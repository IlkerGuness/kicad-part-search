Part Search - KiCad PCM repository

This is a package repository for KiCad's Plugin and Content Manager. Latest version: 3.0.3.

  1. In the KiCad main window choose Tools → Plugin and Content Manager.
  2. Click Manage... next to the repository list, then the + button.
  3. Paste this address, click OK, then Save:
    https://ilkerguness.github.io/kicad-part-search/repository.json
  4. Choose Part Search by İlker Güneş (Zogolder) in the repository list, click Install next to Part Search, then Apply Pending Changes.
  5. Enable the plugin API (Preferences → Plugins) and restart KiCad. The Part Search button is in the Schematic Editor toolbar.

Project page, documentation and issues: https://github.com/IlkerGuness/kicad-part-search
