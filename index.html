Part Search - KiCad PCM repository

This is a package repository for KiCad's Plugin and Content Manager. Latest version: 3.0.2.

  1. In KiCad open Plugin and Content Manager and click Manage... next to the repository list.
  2. Add this URL:
    https://ilkerguness.github.io/kicad-part-search/repository.json
  3. Select the repository, find Part Search and install it.

Project page, documentation and issues: https://github.com/IlkerGuness/kicad-part-search
